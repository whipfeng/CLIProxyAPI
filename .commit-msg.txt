fix: remove billing-header injection from Claude executor for KV cache stability

The x-anthropic-billing-header system block contained dynamic fields (cch=,
cc_version with buildHash) that changed every request, breaking KV cache
prefix matching for ALL providers (Claude, Kimi, Trae, etc.).

Instead of trying to stabilize individual fields, remove the entire
billing-header injection. It's a routing/billing metadata block that has
no functional value for proxy use and only harms cache performance.
